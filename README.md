# Smart Greenhouse Dashboard (ESP32-C3 + MQTT + Node.js)

Dashboard real-time untuk monitoring dan kontrol Smart Greenhouse berbasis IoT dan Fuzzy Logic (ESP32-C3).

## Fitur

- ✅ Monitoring real-time (suhu, kelembapan, cahaya, kelembapan tanah)
- ✅ Kontrol aktuator (Fan, LED, Misting, Water Pump) via PWM/ONOFF
- ✅ Mode AUTO (Fuzzy Logic di ESP32) dan MANUAL (dari dashboard)
- ✅ Multi-user real-time synchronization (Socket.IO)
- ✅ Grafik real-time (Chart.js)
- ✅ Histori data dari Google Spreadsheet
- ✅ Alert & Notifikasi browser
- ✅ Dark Mode
- ✅ Export PDF laporan
- ✅ Responsive (Mobile, Tablet, Desktop)
